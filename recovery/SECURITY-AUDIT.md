# Security audit — 2026-10-20 (Sprint 4)

Scope: the reconstructed application in this repository and the production Supabase
project `xdaxegotsoumwwxjlbnl` (inspected read-only).

## Verified controls

| Area                 | Control                                                                                                                             | Evidence                                                                           |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Tenant isolation     | Every request-path query runs through `tenantDb()`, which forces `organizationId`, rejects foreign IDs and blocks global models     | `src/lib/tenancy/scope.ts`, unit + integration tests (incl. a bug found and fixed) |
| Authorization        | All 25 state-changing server actions call `requireOrgContext(role)` / `requireUser()`; only login, signup and logout are public     | Automated scan of every `"use server"` export                                      |
| Non-member access    | Org pages and CSV exports return 404 (same as "does not exist")                                                                     | HTTP smoke tests                                                                   |
| Authentication       | bcrypt (cost 12, existing `$2b$` hashes verified), constant-time unknown-user path, rate limiting, open-redirect-safe `next`        | `src/lib/auth/*`, tests                                                            |
| Sessions             | 256-bit random tokens; DB stores SHA-256 only; `__Host-`, HttpOnly, Secure, SameSite=Lax; logout and password change revoke         | Integration tests                                                                  |
| SSRF                 | Resolve once, reject any non-public answer (IPv4/IPv6, mapped, NAT64, 6to4, metadata), pinned connection, every redirect re-checked | `src/lib/net/*`, 50 tests                                                          |
| CSRF                 | Server actions (Next.js origin checks); cron endpoint needs a bearer secret (constant-time compare)                                 | `src/lib/auth/bearer.ts`                                                           |
| XSS                  | React escaping; no `dangerouslySetInnerHTML`; URLs restricted to http/https; nonce CSP with `strict-dynamic`, no inline styles      | `src/proxy.ts`; every script tag carries the nonce (verified)                      |
| Headers              | CSP, X-Frame-Options DENY, frame-ancestors 'none', nosniff, Referrer-Policy, Permissions-Policy, HSTS, no `x-powered-by`            | `next.config.ts`, `src/proxy.ts`                                                   |
| CSV exports          | Formula-injection neutralised; `private, no-store`                                                                                  | `src/lib/reports/csv.ts`, tests                                                    |
| Secrets              | Validated env, errors list variable **names** only; keys sent in headers, never URLs or messages; no secrets in Git                 | Tests + pre-commit scans                                                           |
| Production DB safety | `prisma.config.ts` refuses schema-writing commands against the production ref                                                       | Verified for migrate deploy/reset/dev and db push                                  |
| Dependencies         | `npm audit --omit=dev`: **0 vulnerabilities**                                                                                       | 2026-10-20                                                                         |
